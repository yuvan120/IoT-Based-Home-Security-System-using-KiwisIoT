# IoT-Based-Home-Security-System-using-KiwisIoT
An intelligent IoT-based home security system using ESP32, PIR motion sensors, and magnetic door sensors to detect unexpected movement.

## 📌 About the Project

IoT-Based Home Security System Using KiwisIoT is an IoT-based smart home security project designed to monitor home environments and help detect potential security threats in real time.

Using a microcontroller and connected sensors, the system monitors activities such as unauthorized entry, human movement, and unusual environmental conditions.

The collected sensor data is transmitted through Wi-Fi to the KiwisIoT platform, where users can monitor home security status and sensor readings through an online dashboard from anywhere.

When suspicious activity is detected, the system can trigger alerts to help users respond quickly and improve home security.

This project demonstrates how IoT technology can support remote security monitoring, improve household safety, and create a smarter home environment.
